Three steps, in order. [Installation](/docs/getting-started/installation) gets a
server running. [Configuration](/docs/getting-started/configuration) covers every
setting and which ones an administrator owns instead of the environment.
[Deployment](/docs/getting-started/deployment) is what production needs that
local development does not.

Set `SSO_ISSUER` and the defaults are the ones you want.
